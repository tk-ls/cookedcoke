## Rules these follow

From the brand sheet at `branding-assets/cookedcoke-brand-final/README.md`:

- **Full logo minimum width is 180px.** Below that, use the mark alone. The
  header panel clamps to exactly 180px at mobile widths for this reason.
- **Clear space** is 0.26× the mark height between mark and wordmark.
- **Wordmark typeface** is Montserrat Bold (700), SIL Open Font License. The
  rest of the site is set in Montserrat to match.
- **Colours:** `#FE0001` primary, `#B30000` for small text (7.2:1), `#141414`
  wordmark ink. These are `--coke` in the stylesheets — light theme uses the
  `#B30000` value.

The mark is coloured, so it needs no light/dark variant. Don't reintroduce a
theme swap for it.

Two caveats worth knowing:

1. **Check which source file was used.** Some CachyOS logo files are

2. **The licence covers the artwork, not the name.** "CachyOS" is a trademark;
   a copyright licence to the drawing is not a licence to the brand. Not a
   practical concern for a school refreshment service, but it is a separate
   question that CC BY does not answer.

A consequence to keep in mind: a CC BY derivative is not exclusive. Anyone else
may adapt the same original, and this mark cannot be defended against that.
